什么是 0trace？

0trace 是一款基于 WebRTC 的点对点（P2P）文件传输工具。文件直接在您的设备和接收方之间传输，不经过服务器存储，速度快且保护隐私。

发送文件：上传 → 复制链接 → 发送给对方

接收文件：打开链接 → 自动开始接收（无需登录）

重要提示：请保持此页面打开，直到接收方完成下载。双方需同时在线才能传输文件。

隐私政策

数据处理

0trace 使用 WebRTC 点对点技术进行文件传输。所有文件直接在您的设备和接收方设备之间传输，不经过我们的服务器。我们的服务器仅用于建立连接（信令），不存储、不查看、不记录任何文件内容。

无追踪

我们不使用任何分析工具、Cookie 或追踪技术。我们不收集您的个人信息、IP 地址或使用数据。

安全性

文件传输使用 WebRTC 加密连接（DTLS/SRTP）。但请注意，任何获得分享链接的人都可以接收文件，请谨慎分享链接。
